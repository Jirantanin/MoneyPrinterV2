Visual Planner before Asset Generation

แผนนี้ย้ายการตัดสินใจเรื่องภาพออกจาก heuristic ระหว่าง generate asset แล้วทำเป็น visual_plan.json ก่อน เพื่อแก้ 2 ปัญหาหลัก: stock keyword ไม่ตรง และ fallback AI ดูซ้ำกันเกินไป.

Decision

หยุดจูน keyword/fallback ทีละจุด แล้วเพิ่ม planning layer ที่ inspect ได้ก่อนเสียเงิน generate ภาพจริง.

Root Cause Decision too late

ตอนนี้ asset generator คิด keyword และ fallback สดๆ ระหว่างรัน ทำให้ debug ยากและซ้ำง่าย.

New Artifact visual_plan.json

หนึ่งไฟล์ที่บอกทุก scene/asset ว่าควรใช้ stock หรือ AI และใช้ prompt/keyword อะไร.

First Win Inspect first

นนดู plan ก่อน generate ได้ ถ้า keyword แย่จะเห็นก่อนเสียเวลาและเงิน.

Guardrail No live edits

ทำหลัง run จบ รอบแรกแตะ script/asset planning เท่านั้น ไม่แตะ render.

What Changes

Recommended

  • มี review gate ก่อนลงมือ generate จริง

Risks and Countermoves

          honest bits
        

        

          

            

              Planner adds LLM cost
              
Use one compact structured call for the whole episode or deterministic first pass plus LLM repair only when needed.

            

            

              Plan looks good but provider misses
              
Store provider result counts per candidate keyword. If all candidates miss, fallback is justified and visible.

            

            

              AI fallback still repeats
              
Track visual family and camera role across previous assets. Regenerate once with an alternate role when too similar.

            

            

              Too much complexity
              
Keep first pass narrow: secondary assets only. Anchor image, render, audio, and metadata remain unchanged.

            

            

              Thai context gets lost
              
Planner must output English visual briefs from Thai narration. No ASCII-only context gates in the fallback path.

            

            

              Debug data gets noisy
              
Write compact reports: visual_plan.json, stock_query_report.json, fallback_similarity_report.json.
